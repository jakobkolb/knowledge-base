Obsidian vault container {{ include "obsidian.fullname" . }} deployed.

To complete first-time setup, port-forward the VNC UI and open it in a browser:

  kubectl port-forward -n {{ .Release.Namespace }} \
    svc/{{ include "obsidian.fullname" . }} {{ .Values.service.vncPort }}:{{ .Values.service.vncPort }}

Then open http://localhost:{{ .Values.service.vncPort }} and:
  1. Open or create your vault under /config/obsidian/
  2. Install the "Local REST API" community plugin
  3. Enable the plugin and copy the generated API key from its settings

Pass the API key to the mcp-obsidian release:
  secretEnv:
    OBSIDIAN_API_KEY: "<paste key here>"

The REST API is reachable in-cluster at:
  https://{{ include "obsidian.fullname" . }}:{{ .Values.service.restApiPort }}
